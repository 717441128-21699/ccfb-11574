# 车漆光谱比色实验室

网页端车漆调漆比色工具。色卡与配方全部以**光谱反射率曲线**（400–700nm / 10nm，31 波段）存储与计算，不是 RGB——所以能正确复现"日光下一样、车间灯下差一截"的条件等色问题。

## 运行

```bash
npm install
npm run serve    # 打开 http://localhost:8080
npm test         # CIEDE2000 对 Sharma 公开参考数据（34 组）验证
```

## 功能对照

| 需求 | 实现 |
|---|---|
| 色卡/配方存光谱 | `src/pigments.ts` 颜料 K/S 曲线；`src/cards.ts` 色卡 = 配方+效应参数；Kubelka-Munk 单常数混色 |
| D65 / A / F11 光源 | `src/spectral.ts`：D65、F11 表值 SPD，A 光源按普朗克公式解析生成；光谱 × SPD → CIE 1931 XYZ → sRGB |
| 条件等色检查 | 差异报告同时给出三种光源下的 ΔE00；主光源匹配（ΔE≤1）时报告条件等色指数（其余光源最大 ΔE） |
| 铝片闪烁 | `src/render.ts` 微面片模型：每像素固定薄片法线，视角变化时高光逐点跳闪 |
| 清漆层 / 橘皮 | 独立 Fresnel（Schlick, F0=0.04）镜面反射；橘皮 = 双倍频值噪声法线扰动 |
| 翻转效应 | `src/paint.ts` `flopFactor()`：正视亮侧视暗，强度随金属含量与 flop 参数可调 |
| 配方实时重算 | 滑杆 → KM 重混 → 光谱/渲染/报告同帧更新（rAF 合并） |

## 验证

`test/de2000.test.ts`：Sharma, Wu & Dalal (2005) 公开 34 组参考数据，
计算值与参考值最大偏差 **0.000049**（要求 ≤0.1）。
`test/pipeline.test.ts`：理想白 Lab=(100,0,0)、D65 白点 (95.04,100,108.88)、KM 互逆、条件等色构造。

## 已知简化

- 光谱采样 10nm / 31 波段（400–700nm），未做 1nm 插值
- F11 SPD 为近似表值；色卡颜料曲线为合成形态（非实测）
- 清漆-色漆界面多次内反射未建模，铝片取向分布为均匀随机
